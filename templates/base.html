Digital Image Forensics System

A software platform for evaluating digital image authenticity, detecting spliced regions using Error Level Analysis (ELA), calculating cryptographic checksums, and decoding hardware EXIF metadata.

Core Modules

  • Error Level Analysis (ELA)
  • Cryptographic Hashes (SHA-256)
  • EXIF Hardware Fingerprinting
  • Interactive GPS Geolocation

System Architecture

Backend: Python & Flask
Database: SQLite (Local)
Vision: OpenCV & Pillow
Reporting: ReportLab (PDF)
