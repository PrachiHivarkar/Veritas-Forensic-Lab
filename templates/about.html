Role-Based Access Control

Lab Administrator

Role: admin

Maintains records of all registered users, tracks total image analysis activity across the system, manages accounts, and reviews full forensic audit logs.

Forensic Analyst

Role: user

Uploads and analyzes digital images, tunes Error Level Analysis (ELA) parameters, inspects hardware EXIF tags and GPS data, and exports case reports.

Forensic Analysis Techniques Implemented

Cryptographic Verification

Computes MD5, SHA-1, SHA-256, and SHA-512 hashes simultaneously to establish file fingerprints and immutable chain-of-custody.

Error Level Analysis (ELA)

Re-compresses images at controlled JPEG quality levels to detect differences in compression history characteristic of image splicing.

EXIF Hardware Reconstruction

Extracts camera make, model, lens model, shutter speed, aperture, ISO, and software processing signatures (e.g. Adobe Photoshop, GIMP).

GPS Geolocation Mapping

Parses EXIF DMS GPS coordinates into decimal latitude/longitude and pinpoints capture location on an interactive OpenStreetMap layer.

Persistent SQLite Audit Logging

Automatically records forensic scans into a local SQLite database, enabling case tracking and analyst accountability.

Automated Reporting

Generates court-ready PDF documents using ReportLab, structured plain-text files, and machine-readable JSON exports.
